# NotifyBubbles 0.48.14

- 常用容器长按图标上下拖动排序，边缘自动滚动，松手保存顺序。最下方仍是第一项。
- 记住常用容器的滚动位置，下次分屏恢复；当前 App 不可见时自动滚动使其可见。
- 当前 App 图标下方增加红色短横条，覆盖常用、后台及边缘未读图标；保留原有高亮和排序。横条放在图标底部预留区域内，切换时淡入淡出。
- 横屏窗口右下角功能按钮缩至原来的 75%，不透明度 50%；竖屏按钮保持原样。
- 新增绿色功能按钮：单击执行 TrollOpen 1.5.2 顶部绿色区域的长按动作。有展开的横屏窗口时只在最前面的横屏窗口右下角显示；否则在竖屏气泡容器上方显示。没有展开窗口时隐藏。
- 按钮跟随窗口移动并平滑过渡，键盘避让优先，空间不足时隐藏。按下到松手之间窗口改变则忽略本次点击，避免误操作另一个 App。
- 关闭按钮调用 TrollOpen 1.5.2 右侧橙色区域已核对的单击处理器，长按仍一键清理，边缘模式不显示按钮。不会再退回直接关闭窗口的方法；接口不匹配时提示并记录日志。
- 修复 0.48.10 关闭按钮读取手势内部 action 指针导致 SpringBoard 崩溃的问题。同类调试代码也已移除，不再读取手势私有目标列表或 action 内存。
- 分屏容器顶部位于窗口顶部向下 5% 的窗口高度处。键盘避让仍优先。
- 当前 App 不再自动置顶。常用列表保持顺序，只在当前 App 切换或可用高度变化时滚动使它可见。
- 分屏后台和桌面边缘后台容器只保留最近使用的 4 个 App。已有图标相对顺序不变；当前 App 缺席时纳入并替换最久未使用项。分屏常用 App 在上，与后台容器去重；边缘未读气泡不受四个限制，仍单独显示。

上传 NotifyBubbles 文件夹内全部内容覆盖仓库，包括 Makefile、Sources、Tests、Preferences、scripts 和 .github。安装后重新载入桌面。

验证：本地配置、清理脚本和压缩包可检查；Objective-C 测试与 iOS 编译需要 GitHub Actions。未做真机验证，尤其请测试橙色区域动作等效、四项替换、常用列表第五项仅滚动、键盘避让。关闭行为由 TrollOpen 自身处理器决定。

新增接口的签名、单次调用及窗口状态判定已加入 CI 测试；本地不能运行 UIKit 或验证 TrollOpen 真机行为。请测试绿色区域长按等效、横竖屏共存、窗口移动和关闭后的按钮消失。
