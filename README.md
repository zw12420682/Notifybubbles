# NotifyBubbles 0.48.16 测试版

适用目标：iPhone 14 / iOS 16.0.3 / Dopamine RootHide / TrollOpen 1.5.2 隐根版。

## 本次调整
- 边缘后台容器最多显示 7 行，更多应用上下滚动查看，不再截断后台应用列表。
- 下方收纳按钮点击收起/展开后台图标，长按上下移动整组位置。收纳不终止应用。
- 外部未读气泡不受收纳影响。
- 分屏区域按窗口高度上下各留 5%，常用容器利用剩余高度，后台最多显示 2 行。
- 常用应用不在分屏后台容器重复显示，当前图标自动滚动到可见区域。
- 伸出/缩回由 0.6 秒调整为 0.35 秒，停留时间仍为 1 秒。
- 横屏转竖屏后等待窗口稳定，再向 TrollOpen 补发一次当前竖屏内容方向请求，随后刷新宿主布局。

## 真机重点检查
1. 后台超过 7 个，能上下滚动；收纳后新消息仍能出现，后台不会被清理。
2. 收纳按钮长按拖动后位置保留，展开/收起动作正常。
3. 竖屏分屏常用和后台无重复，后台显示 2 行，键盘出现不遮挡输入区域。
4. 使用气泡按钮和 TrollOpen 自带按钮分别横屏转竖屏，等待约 1 秒观察内容；连续操作时也检查。
5. 若仍错乱，请保留错乱截图和 nfb-debug.log，关注 portrait-content 日志，不要把重复旋转恢复当成修复成功。
