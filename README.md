# NotifyBubbles 0.48.22 · Open 1.3.7 专用版

仅适配用户提供的 Open 定制版 1.3.7、iOS 16 / RootHide。

- 移除 NotifyBubbles 的边缘图标入口、收纳按钮、全屏独立图标和对应开关，保留分屏容器及功能按钮。
- 有展开的竖屏窗口：隐藏 Open 自带边缘图标与已展开的边缘面板。
- 只有横屏窗口、小窗或没有窗口：由 Open 原有显示规则决定是否恢复图标。
- 多窗口并存时，只要仍有展开的竖屏窗口就隐藏；停用 NotifyBubbles 后恢复原生规则。
- 沿用 Open 原生隐藏动画，不修改 Open 的设置或通知记录。

上传本目录全部内容（包括 .github）到 GitHub 仓库根目录覆盖。原 Open DEB 不需要修改。
本地配置、脚本与归档检查不等于 iOS 编译或真机验证。请通过 GitHub Actions 编译后测试切换、旋转、小窗与混合窗口。
