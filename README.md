# NotifyBubbles 0.48.27 · Open 1.3.7 专用版

仅适配用户提供的 Open 定制版 1.3.7、iOS 16 / RootHide。

- 移除 NotifyBubbles 的边缘图标入口、收纳按钮、全屏独立图标和对应开关，保留分屏容器及功能按钮。
- 分屏图标（气泡）出现时：隐藏 Open 自带边缘图标与已展开的边缘面板。
- APP 全屏时：边缘图标收起，交给 Open 原生显示规则。
- 其他情况（桌面、只有横屏窗口/小窗、分屏不在左下角）：展开显示，由 Open 原生规则决定。
- 停用 NotifyBubbles 后恢复原生规则；沿用 Open 原生隐藏动画，不修改 Open 的设置或通知记录。

上传本目录全部内容（包括 .github）到 GitHub 仓库根目录覆盖。原 Open DEB 不需要修改。
本地配置、脚本与归档检查不等于 iOS 编译或真机验证。请通过 GitHub Actions 编译后测试切换、旋转、小窗与混合窗口。

新增位置规则：竖屏窗口离开左下角后，分屏容器及功能按钮淡出并停止接收触摸；返回左下角后淡入。判断使用屏幕左边和底边，允许 4 点渲染误差。窗口观察继续运行。边缘图标跟随分屏图标是否真正显示：分屏图标出现时隐藏，分屏图标因离开左下角等原因不显示时恢复由 Open 原生规则决定。

0.48.27：边缘图标的抑制条件从「存在展开的竖屏窗口」改为「分屏图标（气泡）真正显示」，其余状态（APP 全屏、桌面、只剩横屏/小窗）一律交回 Open 原生 shouldShowEdgeIcon 决定。版本号自 0.48.24 起改为 0.48.27。

0.48.24：关闭按钮成功后及最后一个竖屏窗口消失后，在动画结束阶段有限次核对原生边缘图标。仍有竖屏窗口时不恢复，不覆盖 Open 自身开关或托盘状态；增加恢复诊断日志。需真机验证。
