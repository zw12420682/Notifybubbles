# NotifyBubbles 0.48.17 测试版

继续使用 TrollOpen 1.5.2 隐根版，目标设备 iPhone 14 / iOS 16.0.3 / Dopamine RootHide。

## 本次调整
- 分屏保留常用与后台两个容器。后台实际只保留最近使用的两个非收藏应用，而不只是限制可见行数。
- 边缘未读消息图标统一进入容器，不再单独显示或重复显示。
- 收纳只隐藏没有未读消息的图标；新消息自动显示对应图标，未读清空后重新收纳。
- 展开显示全部后台图标，最多显示 7 行，超过可上下滚动；长按收纳按钮调整位置。
- 保留上一版分屏上下 5% 留白和 0.35 秒伸缩动画。
- 旋转方向补偿沿用 0.48.16，本次未进一步修改，也未确认已解决真机问题。

## 上传和编译
上传本文件夹内全部内容到 GitHub 仓库根目录，包含 .github、Sources、Preferences、Tests、scripts、layout 及根目录文件。
Actions 成功后下载 NotifyBubbles-RootHide，解压安装 DEB。

## 测试
本地验证配置、安装清理脚本和压缩包；iOS 编译与真机行为尚未验证。
GitHub Actions 会运行新增的收纳/未读变化/最近两项筛选测试。
真机请测试：收纳后收到消息能显示；读完后自动收纳；展开后全部应用可滚动；分屏后台只出现最近两个且不与常用重复。
