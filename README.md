# NotifyBubbles 0.48.21 · Open 定制版 1.3.7 适配测试版

目标：iPhone 14 / iOS 16.0.3 / Dopamine RootHide，以及用户提供的 Open 定制版 1.3.7。

## 修改
- 将原 1.5.2 混淆窗口接口迁移到此包的 FloatingAppWindow 接口，覆盖打开分屏、窗口识别、吸附、关闭、顶部长按、旋转补偿和桌面冻结的窗口识别。
- 设置增加“显示边缘图标”，默认开启。关闭后隐藏边缘容器、未读图标、收纳按钮和全屏 App 独立图标；分屏容器、功能按钮不受此开关影响。
- 保留 4 秒收纳、边缘 7 行、分屏后台最近 3 个及全屏独立图标半露规则。

## 编译与验证
上传本目录全部内容，包括 .github，覆盖仓库后使用 GitHub Actions 编译。
本地仅配置、接口静态核对与压缩包检查；没有在本机编译 iOS 或完成真机验证。
接口核对详见 OPEN-INTERFACES.md。原 Open 安装包未修改。本测试版针对 1.3.7，不宣称兼容旧 1.5.2。

安装后依次检查：气泡打开分屏、前台转分屏、关闭按钮、绿色按钮、竖屏吸附/横屏/小窗保留、键盘避让、开关关闭与恢复。
旋转补偿已迁移，但不代表先前内容错乱问题已经解决。
