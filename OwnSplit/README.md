# OwnSplit development

Independent Rootless SpringBoard multitasking tweak for iPhone 14 / iOS 16.0.3 / Dopamine RootHide bootstrap.

Scene hosting, floating-window management, and hosted-input lifecycle are adapted from MIT-licensed DualPane. Keep `LICENSE.upstream` with redistributions. SplitOver is only used as design reference until its licensing is established; no source is copied.

This is an experimental development baseline. Keyboard routing/presentation, live orientation changes, and cinematic landscape layout require target-device validation; build success is not proof of runtime behavior.
