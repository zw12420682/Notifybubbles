# NotifyBubbles 0.48.27 · Open 1.3.7 专用版

本次新增自动排列：
- 小浮窗在屏幕顶部从左到右横排一行（不再避让到角落）。
- 小浮窗与横屏窗口作为一个整体，一起受“横屏窗口上下位置”滑块控制；竖屏组保持贴底。
- 不再缩放窗口，保持 Open 的原始大小。
- 窗口数量、方向或大小稳定 0.75 秒后，用 0.35 秒动画排列。拖动中暂缓；只改变位置不会触发重新排列。
- 竖屏转横屏且没有其他展开竖屏窗口时，执行 Open 边缘图标向左划的展开动作，打开原生 App 列表（showTray），而非仅伸出图标。
- 仍保留离开左下角隐藏 NotifyBubbles 分屏容器及功能按钮的规则；仍有竖屏窗口时不恢复 Open 边缘图标。
- 键盘弹出时分屏气泡整体隐藏，不遮挡分屏和键盘；键盘收起后恢复。
- 切换分屏 App 时，若已有小窗，把上一个竖屏分屏缩小为角落小窗；没有小窗则关闭（受“切换时处理上一个竖屏窗口”开关控制）。
- 小窗 App 展开为分屏时，当前分屏 App 变成小窗；当前分屏 App 被缩小为小窗时，分屏自动恢复最近分屏过的上一个 App（按其小窗展开）。
- 设置新增“分屏图标”开关（默认开）：关闭后分屏气泡隐藏，分屏窗口在左下角且在桌面时自动展开 Open 边缘图标的应用列表（左划展开）；未读通知不受影响。

上传本目录全部内容（包括 .github）覆盖 GitHub 仓库。原 Open 安装包不修改。
此版本是适配测试版：本地检查不等于 iOS 编译或真机验证。GitHub Actions 增加直接运行排列算法的 C 测试，覆盖横屏贴顶、小浮窗横排、滑块位置和无效尺寸。
手机重点测试混合横竖窗口、小窗参与、手动拖动、旋转后的图标展开，以及缩放后的触摸和键盘定位。底层 Open 仍可能主动调整窗口尺寸，需要真机验证双方布局是否冲突。

设置新增“横屏窗口上下位置”：0–100，默认 0 贴顶，滑块值直接决定「小浮窗 + 横屏窗口」这个整体的顶部位置；保存后自动应用于当前及下次窗口排列。竖屏组位置不受影响。新增对应的边界和位置算法测试，由 GitHub Actions 编译执行。

分屏的横屏（转屏）按钮取消。竖屏分屏窗口打开时自动套用设置里的“分屏大小（%）”（50–150，默认 100），取代 Open 默认的 0.86 缩放；打开后仍可手动缩放，修改即时生效。
